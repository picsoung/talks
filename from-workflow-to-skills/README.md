# From workflow to skills

Slidev presentation workspace.

## Commands

- `pnpm setup:browsers` installs Chromium for PDF and PowerPoint export after a fresh checkout.
- `pnpm dev` starts the presentation editor and opens it in a browser.
- `pnpm build` creates the production site in `dist/`.
- `pnpm export` writes `from-workflows-to-skills.pdf`.
- `pnpm export:pptx` writes `from-workflows-to-skills.pptx`.

Edit `slides.md` to build the presentation. Replace the marked headshot, screenshot, evidence, directory, and skill placeholders before the event.
